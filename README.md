# task-manager-cicd
Python Task Manager with Docker and GitHub Actions CI/CD

## Task Manager Application

This project is a Python-based task management application.

It allows users to:
- Create and manage tasks.
- View outstanding ToDo tasks.
- View completed Done tasks.
- Run unit tests to check task management functionality.

## Running the Application

Run the task manager using:

python3 todo.py

Run the unit tests using:

python3 todo-test.py
